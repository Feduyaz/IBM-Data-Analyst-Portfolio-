# Web Scraping and Data Collection

This folder contains web scraping exercises and data extraction activities focused on collecting publicly available information from online sources.

### Topics Covered
- Introduction to web scraping
- Understanding HTML structure
- HTML tags and elements
- Extracting information from web pages
- Working with HTML tables
- Collecting structured web data
- Data extraction and transformation
- Preparing scraped data for analysis

### Tools & Libraries
- Python
- Requests
- BeautifulSoup
- Pandas
- Jupyter Notebook

### Skills Developed
- Web data extraction
- HTML parsing
- Data collection
- Data transformation
- Preparing external data sources for analysis

### Purpose
To develop practical data collection skills and understand how publicly available online information can be extracted and transformed into structured datasets for analysis.
