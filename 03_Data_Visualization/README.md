# Data Visualization

This folder contains data visualization exercises, laboratory assignments, and dashboard-related activities completed through the IBM Data Analyst Professional Certificate.

### Topics Covered
- Data visualization principles
- Choosing appropriate chart types
- Bar charts, line plots, and histograms
- Scatter plots and distribution analysis
- Chart customization
- Data storytelling
- Dashboard development
- Communicating analytical findings

### Tools & Technologies
- Microsoft Excel
- IBM Cognos Analytics
- Python
- Matplotlib
- Seaborn
- Jupyter Notebook

### Skills Developed
- Visual data exploration
- Identifying patterns and trends
- Designing meaningful visualizations
- Dashboard creation
- Communicating insights effectively

### Purpose
To develop the ability to transform analytical results into clear, informative visualizations that support business understanding and decision-making.
