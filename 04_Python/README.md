# Python for Data Analysis

This folder contains Python programming exercises and laboratory assignments completed through the IBM Data Analyst Professional Certificate.

### Topics Covered
- Python fundamentals and syntax
- Variables and data types
- Lists, tuples, dictionaries, and sets
- Conditional statements and loops
- Functions and data structures
- Working with Pandas and NumPy
- Data manipulation and transformation
- Data cleaning
- Exploratory Data Analysis (EDA)

### Tools & Libraries
- Python
- Jupyter Notebook
- Pandas
- NumPy

### Skills Developed
- Python programming
- Data manipulation
- Data preparation
- Working with structured datasets
- Exploratory data analysis

### Purpose
To build practical Python programming skills and apply them to real-world data analysis tasks.
