# SQL and Database Analysis

This folder contains SQL exercises and database laboratory assignments completed through the IBM Data Analyst Professional Certificate.

### Topics Covered
- Relational database concepts
- SQL fundamentals
- SELECT statements
- Filtering and sorting records
- Aggregate functions
- GROUP BY and HAVING
- SQL JOIN operations
- Subqueries
- Database querying and analysis

### Tools & Technologies
- SQL
- IBM Db2
- Jupyter Notebook (where applicable)

### Skills Developed
- Retrieving structured data
- Filtering and organizing records
- Combining data from multiple tables
- Summarizing datasets
- Writing analytical SQL queries

### Purpose
To develop practical SQL skills for accessing, querying, manipulating, and analyzing structured data stored in relational databases.
