  # Excel for Data Analysis

This folder contains hands-on Microsoft Excel exercises and laboratory assignments completed through the IBM Data Analyst Professional Certificate.

### Topics Covered
- Spreadsheet fundamentals
- Data organization and formatting
- Excel formulas and functions
- Data cleaning and preparation
- Sorting and filtering
- Pivot Tables and Pivot Charts
- Data summarization
- Spreadsheet-based analysis

### Tools
- Microsoft Excel

### Skills Developed
- Spreadsheet data management
- Data organization and transformation
- Analytical calculations
- Summarizing datasets
- Extracting insights from structured data

### Purpose
To develop practical Excel skills for organizing, analyzing, summarizing, and interpreting data.
